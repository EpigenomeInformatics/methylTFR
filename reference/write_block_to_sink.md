# write_block_to_sink

Write the block to the methylTFR sink

## Usage

``` r
write_block_to_sink(dev_values, grid, i, j, sink)
```

## Arguments

- dev_values:

  A numeric vector of deviation values

- grid:

  A methylTFR grid

- i:

  An integer specifying the row index

- j:

  An integer specifying the column index

- sink:

  A methylTFR sink

## Value

sink
