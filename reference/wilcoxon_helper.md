# wilcoxon test for two groups

wilcoxon test for two groups

## Usage

``` r
wilcoxon_helper(x, groups, alternative)
```

## Arguments

- x:

  a numeric vector of deviations

- groups:

  a character vector of group names

- alternative:

  the alternative hypothesis, one of "two.sided", "greater" or "less".

## Value

a p-value
