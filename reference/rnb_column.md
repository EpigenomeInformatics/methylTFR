# rnb_column

Extract a single sample column from an RnBeads accessor.

## Usage

``` r
rnb_column(accessor, rnb_set, index)
```

## Arguments

- accessor:

  An RnBeads accessor function.

- rnb_set:

  An `RnBSet` object.

- index:

  Integer index of the sample to extract.

## Value

A numeric vector with one value per site.
