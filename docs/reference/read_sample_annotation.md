# read_sample_annotation

Read a methylTFR sample annotation table.

## Usage

``` r
read_sample_annotation(annfile, sampleColName)
```

## Arguments

- annfile:

  Path to a `.csv` or `.tsv` annotation file.

- sampleColName:

  Name of the column holding the per-sample file names.

## Value

A `data.frame` of sample annotation.
