# Kruskal-Wallis Rank Sum Test for multiple groups

Kruskal-Wallis Rank Sum Test for multiple groups

## Usage

``` r
kw_helper(x, groups)
```

## Arguments

- x:

  - a numeric vector of deviations

- groups:

  - a character vector of group names or colnames(deviations)

## Value

a numeric vector of p-values
